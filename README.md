# Iron Man Mod

Experience the power of Iron Man in Minecraft with this comprehensive mod.

## Features

- Full set of Iron Man armor (helmet, chestplate, leggings, boots)
- Flight mechanics with adjustable speed
- Repulsor ray ability for propulsion

## Requirements

- Minecraft 1.20.4
- Fabric Loader 0.14.0 or higher
- Fabric API

## Installation

1. Download the mod JAR file from the [releases page](https://github.com/EnderDevelopment/iron-man-mod/releases).
2. Place the JAR file in your `mods` folder.
3. Launch Minecraft with the Fabric profile.

### Abilities

- **Flight**: Equip the full set of Iron Man armor and press the jump key to ascend or sneak to descend.
- **Repulsor Rays**: Hold the sneak key while flying to activate the repulsor rays for propulsion.

## Configuration

The mod does not have a configuration file. All settings are hardcoded in the mod.
